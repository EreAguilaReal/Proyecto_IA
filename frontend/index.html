        El recorrido de los datos

        Metodología y alcance

        Del dato a la comparación: una secuencia transparente para explorar el comportamiento del modelo.

        1. 01CSV sintético

          Se carga una muestra independiente o un archivo con el formato esperado.

        2. 02Validar y excluir

          Se validan los datos y se excluyen los casos no disponibles para cobro.

        3. 03Preprocesar

          Calculamos la proporción abonada, escalamos las variables numéricas y codificamos la respuesta al contacto.

        4. 04Random Forest

          El modelo estima la probabilidad de recuperación sintética.

        5. 05Comparar el orden

          Los casos se ordenan por probabilidad y se contrastan con el orden del archivo.

        El entrenamiento reproduce 5,000 registros sintéticos del notebook (semilla 42). La muestra de la interfaz contiene 30 casos independientes (semilla 2026) del mismo generador. Las métricas corresponden al conjunto sintético separado para prueba. El CSV original de demostración contiene filas usadas en el entrenamiento.

        Interpretación responsable. La estimación no es certeza de pago, prioridad de política ni evidencia de causalidad. Los resultados requieren supervisión humana.

        F1 resume precisión y cobertura de la clasificación; ROC AUC mide qué tan bien el modelo distingue las dos clases en distintos umbrales. Ambas métricas se calcularon con datos sintéticos separados para prueba.
